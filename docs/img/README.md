# Cover images

Drop hero/cover art for a mystery here and point the world's `coverImage` at it.

- **The Halcyon** expects **`halcyon.jpg`** in this folder
  (`docs/worlds/halcyon.js` has `coverImage: "img/halcyon.jpg"`).
  Until the file exists, the game falls back to the built-in SVG yacht, so
  nothing breaks — the moment you add `halcyon.jpg`, it is used automatically
  on the case's page and on its landing card.

Any image works (JPG/PNG/WebP); wide landscape (~16:9) looks best as a hero.
